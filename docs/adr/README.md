# Architecture decision records

Decisions this project has already made about its own shape. An architecture review should
not re-suggest what is recorded here; if a decision is wrong, write a new ADR that supersedes
it rather than quietly undoing it.

The protocol-level decisions — evidence must be fetched not typed, the gate fails open and
loud, the two overrides, the machine-wide `core.hooksPath` — are recorded in
`research/DISCOVERY.md` under **Already decided**, and in
`docs/superpowers/specs/2026-09-13-research-gate-hardening-design.md`. Those predate this
directory and are treated as ADR-equivalent.

| ADR | Decision |
|---|---|
| [0001](0001-canonical-project-shape.md) | The canonical project shape has one owner (`lib/scaffold.mjs`), and a deployed hook's executable bit is part of its contract |
| [0002](0002-one-reader-for-the-fail-open-posture.md) | Machine-scoped state lives in `lib/machine.mjs`; the fail-open posture has one reader, plus one pinned copy in shell for the missing-kit case. **Refined by [0020](0020-five-trusted-boundaries-that-did-not-hold.md)** on 2026-09-15: its "a broken config never blocks work" holds for a config that was never written and not for one that exists and cannot be parsed — that is the third state, which holds the last config that parsed and otherwise fails closed. ADR-0002 itself is left unedited, in its own words |
| [0003](0003-research-corpus-single-owner.md) | The research corpus has one reader and one writer (`lib/corpus.mjs`); malformation is reported, never absorbed |
| [0004](0004-contract-checks-registry.md) | The contract checks are an ordered registry (`lib/checks.mjs`); the verdict stays one function |
| [0005](0005-firecrawl-adapter.md) | All vendor knowledge lives in one Firecrawl adapter (`lib/firecrawl.mjs`) with an injectable `exec` |
| [0006](0006-bind-the-skill-in-the-project.md) | The Cowork binding is the project's own `.claude/skills/` (`install.mjs --into`); the `~/.agents/skills` mirror is gone |
| [0007](0007-architecture-map-same-commit.md) | `docs/ARCHITECTURE.md` is the map of the code, and it is staged in the same commit as the code it maps — enforced by the commit gate (`architecture-map`); a prompt, not a proof |
| [0008](0008-guarded-paths-are-project-configuration.md) | The map rule's guarded paths are project configuration (`research/kit.json`, defaults `src/lib/bin/scripts/app`); this repo declares its own, enforcement surfaces included |
| [0009](0009-finding-extractor-stays-in-the-collector.md) | The Finding extractor stays in the collector — a dated rejection of the 2026-09-14 review's candidate 5, with the two triggers that expire it (a second consumer of the extractor, or the heuristics outgrowing their file). **Superseded by [0016](0016-finding-extractor-moves-to-its-own-module.md)** on 2026-09-15: trigger 2 fired (the extractor was 460 of the collector's 658 lines). ADR-0009 itself is left unedited, in its own words |
| [0010](0010-machine-roles.md) | The kit runs on two machines: a machine declares `role: collector \| builder` in machine config (default `collector`), a builder's missing Firecrawl credential is informational, and a builder is held to the rule that it must not collect — refused at the collection CLIs |
| [0011](0011-handoff-integrity.md) | The handoff is checked where the corpus arrives: `lib/handoff.mjs` verifies ledger present, every cited capture on disk, chain intact — a blocker on a builder, silent on a collector (whose existing reporters own the same gaps), with one remedy (the collector pushes `research/raw/` including dotfiles). **Refined by [0020](0020-five-trusted-boundaries-that-did-not-hold.md)** on 2026-09-15: the remedy is now chosen from the cause, because a corpus that travelled whole and was rewritten on checkout here is fixed with `.gitattributes` on this machine — the single text sent operators to the collector, and in practice to re-collect, for evidence that was already on disk. ADR-0011 itself is left unedited, in its own words |
| [0012](0012-name-no-builder.md) | The kit names no runtime: capability names everywhere (`editGate`, `--edit-only`, `hooks/edit-gate.mjs`), the runtime's paths as ONE anchored, overridable default (`RUNTIME_ANCHORS` + `runtimePaths`/`skillLocations`), a rename that repairs a stale registration instead of doubling it, and dated records left in their own words |
| [0014](0014-brief-shape-owner.md) | The brief's shape has one owner (`lib/brief.mjs`: `BRIEF_SECTIONS`, which sections are judged, the section reader the audit uses), and "not yet drafted" is a **structural marker** in the scaffold rather than a sentence of template prose — `briefState` → `template \| legacy \| draft \| authored`, with a pre-marker scaffold (`legacy`) refusing loudly instead of guessing |
| [0015](0015-trace-joins-are-lazy-functions.md) | The trace joins (evidence row → its fetch and capture; unknown → the claim it rests on) are **lazy pure functions** on the corpus reader (`traceOf`, `captureOf`, `claimOf` + `capturesByFile`), not precomputed `row.trace` data — the reader is the edit-time gate's read path and must not pay for joins nobody asked for; re-raises the 2026-09-14 review's deferred candidate 3, with a measurement as the expiry trigger |
| [0016](0016-finding-extractor-moves-to-its-own-module.md) | The Finding extractor moves to `lib/finding.mjs` (`firstFinding(markdown, fallback)` is its whole interface) — superseding ADR-0009, whose trigger 2 fired: the extractor was 70% of `lib/collect.mjs`, a second concept in a file that declares one. The collector imports it and does not re-export it; the 17 heuristic tests moved with it |
| [0013](0013-resume-is-documentation.md) | Resuming after an interruption is documentation, not a check: an arriving agent orients from repository state (`doctor`, preflight, the last commit report, this map, the working tree) and resumes rather than restarts — prose in `AGENTS.md`/template, enforced by nothing, because a gate that judged orientation would be wrong |
| [0017](0017-wrong-project-is-asked-not-searched.md) | The wrong project is asked for, not searched for: the project is the cwd and the kit takes no project argument (a flag would make two roots the gate can disagree about); a cwd that is not the project the operator meant is one question, never a filesystem search, an inference from a name, or a remote lookup — prose in `AGENTS.md`/template, enforced by nothing |
| [0018](0018-operator-file-ships-from-template.md) | The operator's file (`START_HERE.md`) ships from `template/` into every scaffolded project — the short human-readable twin of `AGENTS.md`, where things are / how to start / how to resume / credits — and is deliberately NOT a `LAYOUT` entry: no rule needs it to exist, so a project without it reports nothing |
| [0019](0019-audits-bundle-into-one-attachment.md) | Audits bundle into one attachment: `zipAudit` reads the manifest's `latest` pointers (never a directory listing), renders nothing and bumps nothing, and refuses rather than guesses (no audits / several unnamed topics / a manifest naming a missing file). The ZIP container is written in `lib/archive.mjs` — no dependency, no shelling out to a `zip` binary; an exact `--topic` beats prefix matching |
| [0020](0020-five-trusted-boundaries-that-did-not-hold.md) | Five trusted boundaries that did not hold, fixed as one class: no data reaches a **shell** (argv + `shell: false`, the Windows `.cmd` route validated and refusing rather than re-quoted); the collector's **lock** is `O_EXCL`, so exclusivity is the kernel's decision, with an unidentifiable fresh holder waited for rather than broken; a **path list** is data on a pipe, never a growing argv, and a watchdog kill is a named internal error; platform **text handling** is pinned (`.gitattributes` in the repo *and* the template) and a body-hash mismatch is *classified* — line-ending rewrite vs. tampering — so the remedy names the right machine; and the machine **config default** is read in three states, where an unreadable config holds the last one that parsed and otherwise fails closed. Four shared rules: the guarantee belongs to the platform; a data channel is not an argument channel; classify rather than guess; a hardening never moves towards allowing on its own. Refines 0002 and 0011, both left unedited |
| [0021](0021-the-test-harness-awaits-its-tests.md) | The test harness **awaits its tests**: `runPending` is async, a verdict is printed only after the test has settled, and the failure count includes async failures — before, an async test printed `ok` the instant it returned its promise and the runner exited 0 over a failing assertion. One test at a time in registration order (concurrency rejected: shared temp state); a per-test watchdog (`RESEARCH_KIT_TEST_TIMEOUT`, 60s, chosen by measurement — the suite runs in 9s); a timed-out test's promise swallowed so its late rejection cannot crash the runner. Discharges finding 1 of the 2026-09-15 triaged review and the deferral ADR-0020 recorded, both left unedited |
| [0022](0022-build-the-protocol-kit-first-defer-the-release-evidence-validators.md) | Phase 2 builds the protocol kit completely and **defers the release-evidence validator layer** (`release-validator`, `path-authority-validator` and the other three), naming what is delivered and covered by the suite rather than shipping five half-modules to satisfy a module table |
| [0023](0023-an-unestablished-role-does-not-collect.md) | A role the kit cannot establish **does not collect**: `unknown` is a third role *state*, not a declarable value — `machineRole()` resolves to `collector \| builder \| unknown` while `ROLES` stays the two an operator may write, so nobody can configure their way into an ambiguity |
| [0024](0024-the-commit-gate-judges-the-index.md) | The commit gate judges the **index**, every other caller judges the working tree: `materializeIndex` reproduces the index's own bytes in a scratch directory via `git ls-files -z` + `git checkout-index --prefix`, never writing to the working tree, and the verdict carries which one it judged |
| [0025](0025-one-writer-boundary-and-liveness-not-age.md) | **One writer boundary** around the whole durable operation — `collectOne` holds the lock for the cache decision, the adapter call, the capture write, the id allocation, the ledger append and both row updates — and **liveness rather than age** as the staleness test (`kill(pid, 0)`), because a synchronous collector blocks its own event loop and can never heartbeat |
| [0026](0026-a-refresh-triggers-claim-review.md) | A refresh **triggers claim review** and never substitutes silently: a twelfth check, `evidence-supersession`, refuses an unknown resting on a row whose URL has since been re-collected. The old capture is kept — evidence is irreplaceable — but a superseded row may not keep carrying an unknown |
| [0027](0027-search-and-fetch-are-two-seams.md) | **Search and fetch are two seams**, not one adapter: `selectTransport` resolves a fetch provider and a search provider independently, `FETCH_SHAPE`/`SEARCH_SHAPE` are declared, and the return value is *extended* (`{ name, adapter, why }` still means the fetch side) so no existing caller changes. Refines ADR-0005, which stays correct about where vendor knowledge lives. The point is two meters, not a lower unit price — a capture is stamped with what fetched it, and `transport-provenance` is deliberately untouched |
| [0028](0028-the-bundle-is-a-received-state-not-a-live-constraint.md) | The bundle is a **received state, not a live constraint**: `BUNDLE_INDEX.md`'s digests are frozen at the 2026-09-17 handover and never regenerated, because a hash file rewritten whenever it disagrees with reality records nothing. Supersedes ADR-0022's byte-preservation consequence and **restores ADR-0007 in full** — no more `--no-verify` for the map rule. The trade ADR-0022 described was inverted: nothing had ever read those digests, while the map rule is checked mechanically on every commit and caught four real documentation errors in three days. `lib/bundle.mjs` makes the record checkable instead of decorative — unchanged / changed-and-expected / changed-and-**not**-expected, with `EXPECTED_TO_DRIFT` naming only the files the project's own rules require to move |

| [0029](0029-the-validator-layer-arrives-as-a-source-not-a-donor.md) | The validator layer arrives as a **source, not a donor**: the release-evidence modules ADR-0022 deferred turn out to exist on this machine - 1,700 lines, 12 schemas, 61 passing tests - in a tree that is **not a git repository** and has diverged from this one. Absorbing them in one commit would be the project failing its own premise, since it refuses an unaccounted *capture* and could not coherently exempt code. Six rules bind the port: one module per commit, tests green in THIS runner, every module read before it is committed, nothing enters ahead of its dependencies, the map moves in the same commit, and the provenance the source cannot supply is written here |

| [0030](0030-decision-research-lives-in-a-nested-project.md) | Research supporting a repository-level architectural decision lives in a **self-contained project at `docs/decisions/<date>-<decision-name>/`** — scaffolded normally, verified by `cd`-ing into it, and **committed with its ledger**. A scratch project may be used for experiments, but its findings cannot support a committed decision unless the corpus and ledger are preserved. Written after the first attempt at one such decision collected nine pages into a temporary directory and deleted it as cleanup, leaving a recommendation with no provenance under it. Costs no code: the project has always been the cwd (ADR-0017) |
| [0031](0031-actions-first-delivery-and-pin-the-api-version.md) | **Actions-first delivery, and any client pins `X-GitHub-Api-Version`.** Evidence basis: [`docs/decisions/2026-09-21-delivery-architecture/research/BRIEF.md`](../decisions/2026-09-21-delivery-architecture/research/BRIEF.md). The dispatch endpoint returns `204 No Content` under the default `2022-11-28` and `200` with `{workflow_run_id, run_url, html_url}` under `2026-03-10` — verified both ways against this repository, which removed the correlation race that was the main objection to the Actions route. The ZIP is labelled `COLLECTED CORPUS — HUMAN REVIEW REQUIRED` **inside the package**, is delivery and never storage (90 days), and the paid run stays behind a required reviewer. The local `.exe` is deferred on `useVfs` being Stability 1.0, not rejected |

| [0032](0032-one-artifact-contract-for-every-consumer.md) | **One artifact contract for every consumer, and authorization is DERIVED rather than asserted.** One versioned ZIP serves the AI agent, the Actions workflow, the future Windows app and a person with unzip: `manifest.json` is the machine entry point, `README-FIRST.md` the human one, and the producer renders the second from the first so they cannot disagree. `createArtifact` takes no authorization argument and the CLI has no `--build-authorized` — `state`, `kind`, `buildAuthorized`, `review.*` and `gate.*` all come from running the real gate, with `env` defaulting to `{}` so a packaging shell's `GATE_OFF` cannot leak into a package that outlives it. `findingsReviewed` is answered negatively rather than graded: a Finding still byte-identical to the extractor's output was demonstrably never rewritten (the line ADR-0013 drew, uncrossed). The validator is offline and read-only, and refuses every structural fault from the central directory **before** inflating anything. `PASS` and `buildAuthorized` stay separate fields, because exit 0 on a collected corpus is the most misreadable result the tool produces |

| [0033](0033-the-collector-refuses-rather-than-degrades.md) | **The collector refuses rather than degrades, and no dispatch input reaches a shell.** `collect.yml` implements ADR-0031 against ADR-0032's contract, separate from `live-collection.yml` because "does the adapter work" and "collect this, for a person, now" deserve different approvers. The environment is the spend gate — and is **checked for existence**, because GitHub silently *creates* an unprotected environment when a workflow names one that is missing (E-06), which would remove the approval gate without failing anything. The honest limit is written in the file: GitHub exposes no scope information, so the marker proves the environment was configured and **cannot** prove a repository-level value did not serve the secret. No `http-keyless` fallback: a missing credential refuses rather than shipping a quietly worse corpus under the same artifact name. Every input arrives through `env:` and then an argv array — `${{ inputs.x }}` in a `run:` block is substitution *before* the shell parses, so a backtick in a topic executes. The test enforcing that scans every workflow and found `live-collection.yml` had been doing it since it was written; fixed here **Amended the same day**: the required reviewer is dropped and the environment kept. A reviewer approving a *dispatch* is a spend gate, not a review — nothing is collected yet to judge — and it makes autonomous dispatch impossible. The environment stays because it was never about approval: it is the only place the credential is unreadable by every other workflow. Spend is bounded by `max_pages`, the depth tier and the vendor's 402-at-zero cap. The control that replaces the reviewer is **token scope**: a fine-grained PAT with `Actions: read and write` on one repository, driven by `bin/collect-remote.mjs`, which takes **no `--token` flag** and redacts by pattern rather than by remembering its own value |
