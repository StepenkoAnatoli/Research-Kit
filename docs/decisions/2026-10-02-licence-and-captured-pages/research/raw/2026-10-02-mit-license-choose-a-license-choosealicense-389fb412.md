### How to apply this license


 Create a text file (typically named LICENSE or LICENSE.txt) in the root of your source code and copy the text of the license into the file. Replace [year] with the current year and [fullname] with the name (or names) of the copyright holders.





#### Optional steps






 Add **`MIT`** to your project’s package description, if applicable (e.g., [Node.js](https://docs.npmjs.com/cli/v7/configuring-npm/package-json#license), [Ruby](https://guides.rubygems.org/specification-reference/#license=), and [Rust](https://doc.rust-lang.org/cargo/reference/manifest.html#the-license-and-license-file-fields)). This will ensure the license is displayed in package directories.
