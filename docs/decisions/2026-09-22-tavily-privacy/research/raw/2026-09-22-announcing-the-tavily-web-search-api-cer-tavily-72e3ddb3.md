## What the certification includes

The certification is structured into three modules. Each module teaches a core skill that contributes to a complete agent workflow.

### Module 1: How agents search the web

Learn why agents cannot rely on internal reasoning, how keyword and semantic search differ, why hybrid search matters, and how recall, precision, recency, and domain trust shape search quality. You also explore common failure modes and how to avoid them.

### Module 2: Using Tavily Search

Learn how the Tavily Search API works and how to configure depth, recency filters, topic controls, domain filters, raw content settings, and result limits. You also pick up cost and performance best practices to build fast, accurate agents.

### Module 3: Advanced Tavily Tools

Dive into Extract, Crawl, and Map endpoints. Learn how Extract retrieves clean text, how Crawl explores domains across multiple hops, and how Map reveals a site’s structure. This module shows you how to build large scale research and ingestion workflows beyond basic search.
